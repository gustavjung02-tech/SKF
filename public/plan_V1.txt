Yêu cầu C — Logic tìm mã phải sát theo đầu mã:
1. Query "62" phải tìm các mã có normalizedCode/code bắt đầu bằng "62".
2. Không được dùng contains cho query ngắn 1-3 ký tự.
3. Query số ngắn:
   - "6" chỉ match code bắt đầu bằng 6.
   - "62" chỉ match code bắt đầu bằng 62.
   - "630" chỉ match code bắt đầu bằng 630.
4. Query chữ kỹ thuật:
   - NU, NJ, NUP, UCP, UC, IR, LG, TMFT, TIH, TKSA
   - chỉ match code bắt đầu bằng prefix đó.
5. contains chỉ được dùng khi query dài >= 4 ký tự và chỉ dùng như điểm phụ.
6. Ví dụ bắt buộc:
   - query "62", nhóm "Vòng bi SKF": phải ra các mã bắt đầu bằng 62 nếu có trong data.
   - query "6", d=90: không được ra IR 90X100X26.
   - query "IR", d=90: lúc đó mới được ra IR 90X100X26 nếu có.
